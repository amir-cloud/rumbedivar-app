# Screener — RumbDivar Discovery (Persian copy-ready)
Use in Google Form / Typeform / panel tool. All questions optional except marked *.

**Intro (show first):**
> سلام! ما داریم روی اپ «روم به دیوار» کار می‌کنیم؛ فروشگاه اینترنتی برای خریدهای خصوصی و حساس.
> این نظرسنجی ۳ دقیقه است. اگر واجد شرایط باشید، برای مصاحبه ۴۵ دقیقه‌ای (صوتی/تصویری بدون اجبار دوربین، با نام مستعار) دعوت می‌شوید + هدیه نقدی/کارت هدیه.
> اطلاعات شما ناشناس می‌ماند و می‌توانید هر سوالی را بی‌پاسخ بگذارید.

## Questions

1. *بازه سنی؟ [single-select]
- ۱۸-۲۴ / ۲۵-۳۴ / ۳۵-۴۵ / ۴۶+  → recruit first three only

2. *در ۶ ماه گذشته آنلاین خرید کرده‌اید؟ کجا؟ [multi]
- دیجی‌کالا / اسنپ‌مارکت / اینستاگرام / سایت داروخانه / خیر، خرید نکردم → exclude اگر «خیر»

3. *تا حالا شده خرید یک محصول بهداشتی/شخصی/صمیمی را عقب بیندازید یا منصرف شوید چون خجالت کشیدید حضوری بپرسید یا نگران بودید کسی بفهمد؟ [single]
- بله / خیر / ترجیح می‌دهم نگویم → must be «بله» to qualify

4. با چه کسی زندگی می‌کنید؟ [single — quota]
- تنها / همسر/پارتنر / والدین / هم‌خانه / خوابگاه

5. سفارش‌های آنلاین را معمولا کجا تحویل می‌گیرید؟ [multi]
- درب منزل / محل کار / نقطه تحویل/لاکر / آدرس آشنایان

6. شهر محل سکونت؟ [short text]
→ کدگذاری: تهران/کلان‌شهر vs شهرستان (need mix — small-city anonymity differs)

7. جنسیت؟ [single — quota 50/50 + option]
- زن / مرد / غیرباینری / ترجیح می‌دهم نگویم

8. راحتی خرید آنلاین شما؟ [single — mix]
- فقط دیجی‌کالا / هم دیجی‌کالا هم اینستاگرام / کم خرید می‌کنم

9. *حاضرید در مصاحبه ۴۵ دقیقه‌ای صوتی (بدون اجبار دوربین، با نام مستعار، ضبط فقط برای استفاده داخلی) شرکت کنید؟ [single]
- بله / خیر → must be بله

10. برای مصاحبه، مصاحبه‌گر خانم را ترجیح می‌دهید یا آقا؟ [single]
- خانم / آقا / فرقی ندارد → honor choice

11. در مصاحبه با چه نامی صدایتان کنیم؟ [short text — alias]

12. شماره تماس / آیدی تلگرام برای هماهنگی؟ [short text]

13. در ۳ ماه گذشته در تحقیق کاربری دیگری شرکت کرده‌اید؟ / در شرکت رقیب (دیجی‌کالا، اسنپ) کار می‌کنید؟ [single Yes/No — exclude if Yes]

## Screening logic
QUALIFY if: Q1 in 18-45 AND Q2 != never AND Q3 == بله AND Q9 == بله AND Q13 == خیر (both).
Then balance quotas: gender, city size, household, channel.
Over-recruit 12 to get 8-10 shows. Incentive: مصاحبه ۴۵ دقیقه‌ای ~ معادل ۴۰-۶۰ دلار (کارت هدیه/نقدی) + نظرسنجی ۱۰-۱۵ دلار.
