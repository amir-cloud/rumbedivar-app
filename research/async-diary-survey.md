# Async Survey + 3-Day Diary — RumbDivar (Persian copy)
Tool: Google Form / Typeform / Porsline. Time: 5 min survey + optional diary. Incentive: 10-15 USD equiv.

## Intro
> ۳ دقیقه برای خریدهای خصوصی! جواب‌ها ناشناس است. در آخر می‌توانید برای دفترچه ۳ روزه (ویس تلگرام) داوطلب شوید + هدیه بیشتر.

## Closed (8)
1. در ۶ ماه گذشته چند بار خرید آنلاین داشتی؟ [۰ / ۱-۲ / ۳-۵ / ۶+]
2. کدام دسته را حضوری خجالت می‌کشی بخری؟ [multi: بهداشتی جنسی / بهداشتی شخصی / لباس زیر / تست بارداری/دارو / محصولات زیبایی خاص / کتاب/محتوای حساس / بگو نمی‌خواهم بگویم / دیگر]
3. آخرین بار که منصرف شدی یا عقب انداختی، چرا؟ [multi: ترس از قضاوت فروشنده / ترس از دیدن خانواده/همکار / بسته/لیبل لو می‌ره / پیامک بانکی / پیک حرف می‌زنه / قیمت / اعتماد به کیفیت]
4. معمولا از کجا می‌خری وقتی حساسه؟ [دیجی‌کالا / داروخانه اینترنتی / اینستاگرام / حضوری شهر دیگر / سپردن به دیگری / نمی‌خرم]
5. ترجیح تحویل برای خرید حساس؟ [درب منزل / محل کار / لاکر/نقطه تحویل / آدرس آشنا]
6. ترجیح پرداخت؟ [آنلاین / درب منزل نقدی-کارتی / کیف پول]
7. برای «بسته کاملا خنثی + پیک بدون لوگو + فاکتور خنثی» چقدر بیشتر می‌دی؟ [۰ / ۵-۱۰٪ / ۱۰-۲۰٪ / اصلا نمی‌خوام]
8. مهم‌ترین ویژگی اپ خصوصی؟ [rank: بسته خنثی / تحویل لاکر / اسم خنثی در بانک / آیکون مخفی اپ / قفل اثر انگشت / نوتیف بدون پیش‌نمایش / چت پشتیبانی ناشناس]

## 3-Day Diary (Telegram/WhatsApp, optional opt-in)
> «۳ روز، هر روز ۱ ویس ۱ دقیقه‌ای: امروز چیزی لازم داشتی که نخریدی؟ کجا دیدیش؟ چی جلوت رو گرفت؟ عکس (با سانسور) از بسته/پیامک آزاردهنده هم می‌تونی بفرستی.»
Prompt daily at 19:00 Tehran. Researcher acknowledges, no judgment, no follow-up probing beyond «ممنون، می‌تونی بیشتر بگی کی نگرانت کرد؟»
